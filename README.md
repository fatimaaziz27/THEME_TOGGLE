# THEME TOGGLE

A simple interactive webpage built using **HTML, CSS, and JavaScript** to demonstrate how JavaScript can make a webpage dynamic and interactive.

## About

This project demonstrates different interactive web elements such as **buttons, toggles, dynamic text updates, and theme switching**.

It was created to practice JavaScript DOM manipulation, event handling, CSS styling, responsive design, and interactive webpage development.

## Features

* Dark Mode and Light Mode toggle
* Interactive buttons
* Dynamic text updates
* Content toggling
* Random text generation
* JavaScript-based interactions
* Responsive webpage layout
* DOM manipulation
* Event handling
* CSS class switching

## Technologies Used

* HTML5

## How It Works

### 1. Interactive Buttons

Buttons trigger JavaScript functions when the user interacts with them.

### 2. Dynamic Content

JavaScript updates text or content on the webpage based on user actions.

### 3. Theme Toggle

The theme button switches the webpage between **Light Mode** and **Dark Mode** by changing the page's styling.

### 4. Random Text

JavaScript can select text from an array and display different content dynamically.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Interact with the buttons and theme toggle.

No additional installation is required.
